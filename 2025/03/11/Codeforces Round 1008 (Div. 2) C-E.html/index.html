C Breach of Faith

题目入口：https://codeforces.com/contest/2078/problem/C

思路：我们观察发现偶索引n个数 但是奇数索引有n+1个数 所以我们对b数组排序，把前n-1个放在偶索引，其他放在奇索引就可以了，最后一个数一定会比最大的两个数之和大，也就可以做到两两不同

代码: https://codeforces.com/contest/2078/submission/309837445

D Scammy Game Ad

题目入口: https://codeforces.com/contest/2078/problem/D

思路：由于最开始左右两条路都有1个人，所以对于所有的+是没有必要管的，因为安排人之后不会变道，所以你只需要考虑×，也就是在一步步走的时候，遇到×就让前面所有没有安排道路的人都走这条道，最后统计答案

代码: https://codeforces.com/contest/2078/submission/309854197
我这里是对suf进行处理下个一最近最大的×在左还是右，实际并不需要这么复杂

E Finding OR Sum

题目入口: https://codeforces.com/contest/2078/problem/E

思路：题目中其实有明显暗示，就是你只能进行两次查询，就很容易想到应该是0101010101和1010101010，此时我们可以需要推断出x,y，
假设x,y是0000000000,0000000000,那么我们得到第一个回答：0101010101 x 2 第二个回答：1010101010 x 2
如果x,y是0000000001,0000000000,那么就会得到第一个回答：0101010101 x 2 第二个回答：1010101010 x 2+0000000001
如果x,y是0000000001,0000000001,那么就会得到第一个回答：0101010101 x 2 第二个回答：1010101010 x 2+0000000010
如果x,y是0000000010,0000000000,那么就会得到第一个回答：0101010101 x 2+0000000010 第二个回答：1010101010 x 2
如果x,y是0000000010,0000000010,那么就会得到第一个回答：0101010101 x 2+0000000100 第二个回答：1010101010 x 2
如果x,y是0000000011,0000000011,那么就会得到第一个回答：0101010101 x 2+0000000100 第二个回答：1010101010 x 2+0000000010
这里就可以观察到规律，其实当x,y的第i位都是1时 根据i的奇偶性 那么得到的答案第i+1位二进制会是1
当x,y的第i位只有一个是1时，那么得到答案第i位二进制会是1
代码: https://codeforces.com/contest/2078/submission/309921531
