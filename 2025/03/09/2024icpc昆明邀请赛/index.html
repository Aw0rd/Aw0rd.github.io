B. Gold Medal

题目：
这一周非常忙碌！这个周末，将有 n 场编程竞赛同时进行。

每场竞赛会根据参赛队伍的数量发放金牌。具体来说，每场竞赛会根据每 k 支队伍发放一枚金牌。也就是说，如果一场竞赛有 t 支队伍参加，那么这场竞赛会发放 ⌊ t / k ⌋ 枚金牌，其中 ⌊ x ⌋ 表示不超过 x 的最大整数（即向下取整）。

目前，每场竞赛的参赛队伍数量为 ai。

宝宝是某大学的教练，他有 m 支队伍，目前尚未决定这些队伍应该参加哪些竞赛。请帮助他为每支队伍分配竞赛，确保总共发放的金牌数量最大化。

思路：
签到题，首先，对每个竞赛计算可获得的金牌数量，再将队伍分配给最能获得金牌的竞赛。然后按此策略进行分配，直到所有队伍都被分配完为止。

G. Be Positive

题目：
找出满足以下约束条件的 0, 1, 2, …, (n-1) 的词典最小排列 p0, p1, p2, …, pn-1：
对于所有 0 ≤ i < n**，满足 **p0 ⊕ p1 ⊕ … ⊕ pi > 0，其中 ⊕ 表示位排中的异或运算。

如果存在一个整数 0 ≤ k < n，使得所有 0 ≤ i < k 和 pk < qk 都是 pi = qi，那么我们说长度为 n 的整数序列 p0, p1, …, pn-1 在词法上小于长度为 n 的另一个整数序列 q0, q1, …, qn-1。

思路：
签到题，可以考虑通过逐个计算前 i 个数的异或和来解决，当prei = i + 1， 可以知道prei ⊕ (i+1) 一定不为 0，一旦遇到这个情况，直接交换 i 和 i+1 即可。

I. Left Shifting 2

题目：
给定一个由小写英文字母组成的字符串，如果所有相邻的字符都不同，我们就说这个字符串很美。例如，icpc 和 kunming 是美丽的，但 hello 不是，因为它的 3-rd 和 4-th 字符是相同的。

给定一个长度为 n，由小写英文字母组成的字符串 S = s0s1…sn-1，设 f(S, d) 是将 S 向左移动 d 次得到的字符串。即：

f(S, d) = s(d+0) mod n, s(d+1) mod n, …, s(d+n-1) mod n。

让 g(S, d) 成为使字符串 f(S, d) 变得优美所需的最小操作次数。每次操作可以将 f(S, d) 中的一个字符改成任何小写英文字母。

找出能使 g(S, d) 最小化的非负整数 d，并输出最小值。

思路：
考虑到字符串 S 可以左移任意位，实际上可以将字符串视作一个环，切换到任意位置后，计算最小操作次数，使得相邻字符不相同。
当字符串的字符完全相同时，操作次数是固定的，比如：”aaa” 需要一次，”bbbb” 需要两次，操作次数为 len / 2。
对于最优切割位置，我们应从两个相同字符之间切开。
对于偶数长度的字符串，将其切开并分成两部分的操作次数较少，而对于奇数长度的字符串，切割与否对结果没有影响。

A. Two-star Contest

题目：
由于各种原因，教育专家将对 n 项竞赛进行评级。专家们已经确定了每项竞赛的评级，其中第 i 项竞赛被评为 si 星级竞赛。

据说，每项比赛都是根据 m 个属性来评定的，其中第 i 次比赛的 j 个属性表示为 pi,j，其值范围为 0 至 k（均包括在内）。一项竞赛的得分是由其所有 m 属性的总和计算得出的。也就是说，假设 vi 是第 i 项竞赛的得分，那么我们就得到了：

$$v_i = \sum_{j=1}^m p_{i,j}$$

星级越多，得分自然越高。专家们要求，对于任意两个竞赛 1 ≤ i, j ≤ n，如果有 si > sj，那么一定有 vi > vj。

不幸的是，专家们忘记收集某些竞赛的某些（甚至全部）属性值。作为专家的助手，你需要补上缺失的值，以便上述约束条件在任意两个竞赛中都成立。

思路：
这道题的解法可以采用排序和贪心的策略。首先按照竞赛的星级 si 对竞赛进行排序，同时记录每项竞赛的原始索引。然后我们用一个数组记录每项竞赛已知的得分和未评定的部分。接着按 si 从大到小处理这些竞赛，对于每项竞赛：

  • 确保若 i < j 且 si < sj，则 vi < vj。
  • 在处理过程中，尽量将未评定的属性值填充为最大值 k，使得得分满足条件。

E. Maximize GCD

题目：
给定一个长度为 n 的整数序列 a₁, a₂, ⋯, aₙ 和一个非负整数 k，最多可以进行一次下面的运算：选择 l 和 r 这样的两个整数 1 ≤ l ≤ r ≤ n，然后对每个 l ≤ i ≤ r 将 aᵢ 改为 **(aᵢ + k)**。

目标是最大化整个序列的最大公因子。

如果对于所有的 1 ≤ i ≤ n 而言， aᵢ 都能被 g 整除，那么整数 g 就是整个数列的公因子。

思路：
根据题意，我们的目标是找到一个最优的区间 **[l, r]**，使得在对该区间内的元素加上 k 后，整个序列的最大公因子最大。

我们可以通过以下方式来思考和实现：

  1. 前缀和后缀 GCD 数组：

    • 用一个前缀数组 pre 维护前 i 的元素的 GCD。
    • 用一个后缀数组 suf 维护从 i 到 n 之间所有元素的 GCD。

    通过这种方式，我们可以方便地计算出选择某个区间时左侧和右侧的 GCD。

  2. 区间合并：

    • 如果 **pre[i] = pre[i-1]**，我们可以将这些区间合并。这样有助于减少计算量，因为两个相邻的元素如果 GCD 相同，合并的结果会更优。

  3. 枚举区间：

    • 我们可以枚举前缀和后缀区间，用gcd(pre[l-1], suf[r+1], gcd(a[l], a[l+1], …, a[r])) 来更新答案，利用前缀和后缀的 GCD 来避免重复计算。

  4. 复杂度分析：

    • 由于数据范围最大为 1e9，这意味着区间的最大长度不到 32，这样的区间可以在 O(n * (log n)²) 内完成。
    • 如果用线段树来优化查询，可以达到 O((log n)³) 的查询复杂度。

J. The Quest for El Dorado

题目：
这个王国有 n 个城市，m 条双向铁路连接着各个城市。每条铁路由某个公司运营，且有一个长度。

您想从 1 城市出发，环游全国。为了旅行，您购买了 k 张火车票。每张车票可以用两个整数 aᵢ 和 bᵢ 来表示，表示如果您使用这张车票，您可以一次性乘坐几条铁路，只要这些铁路都是由 aᵢ 公司运营，且总长度不超过 bᵢ。使用车票时，也可以只在当前城市停留。每次只能使用一张车票，每张车票只能使用一次。

您的目标是，在每次使用一张车票后，判断能否从 1 城市出发，经过 k 张车票，最终到达其他城市。

对于每个城市，确定在使用所有 k
车票后是否有可能到达该城市。
思路：
其实看完题就知道是dijkstra,通过维护当前使用的是第几张车票，当前车票已经使用过的路程，当前到达的城市，一步一步的更新，如果下一个城市的铁路是当前车票的铁路公司运营，并且车票剩余长度比铁路距离长，那就直接更新，
否则就去找下一张满足条件的车票，这里可以通过st表+二分实现查找，这样不断更新，时间复杂度O(n * (log n)²)
